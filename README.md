# Family Hotel Room Booking System

## Project Description
The Family Hotel Room Booking System is a Python-based project used to manage hotel room bookings. It allows users to view rooms, book rooms, cancel bookings, view booking details, and calculate the total bill.

## Objectives
- To make hotel room booking simple.
- To manage room availability.
- To calculate the total booking bill.
- To provide an easy menu-based system.

## Features
1. View Rooms
2. Book Room
3. Cancel Booking
4. View Booking Details
5. Calculate Bill
6. Exit

## Technologies Used
- Python
- VS Code
- GitHub

## How to Run
1. Open the project in VS Code.
2. Open the Python file.
3. Run the program.
4. Select the required option from the menu.
